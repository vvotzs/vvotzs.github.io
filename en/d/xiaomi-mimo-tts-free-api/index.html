Highlight

Three MiMo-V2.5-TTS speech models are free for a limited time and skip Token Plan credits, at RPM 100 and TPM 10M per model

What you get

Xiaomi's MiMo platform lists three MiMo-V2.5-TTS models as free for a limited time: mimo-v2.5-tts synthesises preset premium voices including a singing mode, -voicedesign creates a new voice from a text description and -voiceclone reproduces a target voice from a few audio samples. The API pricing page, updated 18 November 2026, still says the TTS series is free for a limited time, and the usage FAQ of 19 November says the whole TTS line consumes no plan credits. Each model takes 8K tokens of context, outputs up to 8K, runs at 100 RPM and 10M TPM. The API is OpenAI-compatible at https://api.xiaomimimo.com/v1, with text to speak in the assistant role and a user message for style such as speed, emotion or role-play.

Conditions

Register on Xiaomi's MiMo platform and create an API key (a mainland number for the China site); the limited free period is set and ended unilaterally with no date published; cloning and designing voices must not copy anyone without permission; commercial and compliance responsibility rests with the caller; streaming needs pcm16 for concatenation.

Steps

  1. Register on mimo.mi.com and create an API key
  2. Point the OpenAI SDK at base_url https://api.xiaomimimo.com/v1 with model mimo-v2.5-tts (or -voicedesign / -voiceclone)
  3. Put the text in role=assistant and style instructions in role=user, and set format and voice under audio
  4. Check the console billing detail to confirm usage still bills at zero, i.e. the promotion is still live

Watch out

The free period can end or switch to per-use billing at any time with no committed end date, so check the pricing page before building on it; RPM 100 limits concurrency and long texts queue; voice cloning raises consent issues and may face extra review; the domestic site needs a mainland phone number and the overseas site bills in USD with separate quotas.
