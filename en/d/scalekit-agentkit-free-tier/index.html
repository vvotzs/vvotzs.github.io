Highlight

One MCP gateway across 1,100+ connectors and 55,000+ tools (Salesforce, GitHub, Slack, Google Drive…), with every action run as the user who asked, inside the scopes they granted. The free tier includes 10,000 tool calls and 10,000 trigger events a month.

What you get

Scalekit's AgentKit is an MCP gateway for agents headed to production (No. 6 on the Product Hunt November 2026 monthly leaderboard). It puts 1,100+ connectors and 55,000+ tools — Salesforce, GitHub, Slack, Google Drive and more — behind one gateway and handles the OAuth and integrations, so every action runs as the user who asked, within the scopes that user granted. Virtual MCP Servers give each agent only the tools its job needs; custom connectors add internal APIs; Triggers start an agent the moment an email lands; every call is logged. The official pricing page lists Free at $0/month: 10,000 tool calls, 10,000 trigger events, unlimited connected accounts, 1,100+ connectors and 55,000+ tools, bring-your-own credentials, community and email support. Growth is $99/month with 100,000 tool calls plus $0.50 per 1K after that, and 50,000 trigger events plus $3 per 1K.

Conditions

The free tier expects you to bring your own OAuth credentials for each service; Scalekit does not apply for them for you. Allowances reset monthly. Past the free allowance you move to Growth ($99/mo) or pay per use. SSO, SCIM, BYOK, HIPAA BAA and VPC/on-prem are Enterprise only.

Steps

  1. Sign up at scalekit.com and create an environment
  2. Pick the connectors you need in the dashboard (GitHub, Slack, Google Drive…) and enter your own OAuth credentials
  3. Create a Virtual MCP Server carrying only the tools this agent needs and copy its MCP address
  4. Add the address to Claude, Cursor or your own agent and complete one authorised call end to end
  5. Watch the 10,000-calls-a-month free allowance on the usage page before deciding to upgrade

Watch out

The official page contradicts itself: the Free card says 10,000 tool calls a month while the comparison table below lists 5K for Free, so check your own dashboard after signing up. The free tier needs your own OAuth apps and credentials, so it is not plug-and-play. Overage is $0.50 per 1K calls, which adds up quickly on busy agents.
