To promote Vibe + Le Chonk (Mistral Large 4) Mistral released limited places: European developers redeem code LECHONK for 3 months of Vibe Pro, including a monthly API allowance

What you get

On 17 November Mistral AI released limited free 3-month Vibe Pro places to European developers to mark the launch of the open model Le Chonk (Mistral Large 4, 1 trillion parameters with about 52 billion active) combined with Vibe, using code LECHONK. Vibe Pro normally costs $14.99/mo before tax, so three months saves about $45 and includes higher message and web-search limits, expanded Vibe capacity, all-day CLI/IDE/web agentic coding and a monthly API allowance. Places ran out that day and Mistral said on X that more might come the next day; on 11-18 the community saw the code go from "unavailable" back to claimable after a restock, so it's issued in batches. Re-check (2026-11-20 03:30): Mistral restocked once on 11-18 alongside the Vibe Desktop launch, but users again reported "This code is no longer available" the same day. From 11-19, AI Promo Now marks it "verified: no longer works" and mydealz lists it as ended, while users on X are still asking @MistralAI for another drop. It is archived as sold out; if codes return, it can be revived.

Conditions

European developers only; limited places, first come first served, and the code shows "This code is no longer available" until restocked; redeem while signed in to a Mistral account; a valid payment method is needed and community reports say zero-balance virtual cards usually pass verification (a data point, not an official promise); it renews at $14.99/mo, so cancel manually.

Steps

  1. Connect through a European node and sign in to a Mistral account (register first if needed)
  2. Open the redemption page at admin.mistral.ai and enter code LECHONK
  3. Confirm Vibe Pro is $0 for the first 3 months and submit
  4. Cancel the renewal on the subscription page before it ends

Watch out

Archived as sold out: stock can return at any time, and failing to redeem is normal. Non-European accounts or risk checks may fail outright. Anyone who already redeemed still auto-renews at $14.99/month unless cancelled.
