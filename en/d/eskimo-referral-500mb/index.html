What you get

Eskimo's referral reward: a new user registers with someone else's code (or through their invite link) and both sides get 500MB of global data; the referrer gains 500MB per success up to 15GB (30 referrals), and the reward data lasts about 2 years without expiring and stacks with the official 250MB free allowance. Arabic-language X deals accounts shared this heavily in 2026-10 (saying 500MB on signup and up to 15GB), matching third-party referral sites; the official Invite Friends page exists, but confirm the exact numbers on the app's invite page (to be confirmed).

Conditions

Eskimo new users only; the code must be entered at signup or within 24 hours after; an eSIM-capable unlocked phone; one account per device; the referral cap and validity are whatever the app's invite page says (to be confirmed).

Steps

  1. Download the Eskimo app (iOS / Android)
  2. Enter a valid referral code in the referral or gift code field at signup (from the official invite page or a friend)
  3. Check the Data page for the 500MB and add the official 250MB new-user allowance
  4. Install the eSIM and turn on data roaming on arrival

Watch out

The 500MB is a referral reward, not a long-term plan; the 15GB cap and validity aren't stated on the official page and are to be confirmed; entering a stranger's code gives them the reward, so use a friend's if that matters.
