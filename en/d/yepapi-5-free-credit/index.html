Highlight

Sign up with Google or GitHub and $5 lands immediately with no card; one API key reaches 184-190 endpoints across SERP, scraping, YouTube, TikTok, Reddit and X data from $0.01 a call, failed calls are free and the balance never expires

What you get

YepAPI is a unified pay-per-call API: one x-api-key covers 184-190 data endpoints (Google SERP, keywords, backlinks, scraping, Amazon, Walmart, Reddit, X, TikTok and YouTube data) plus 139 chat models and 147 image, video and audio models. Pricing is per call — $0.01 per 10 SERP results, keyword research from $0.03 — with no monthly fee, no minimum and no charge for failed requests. Sign-up includes $5 of credit (stated in both the FAQ and the docs, no card needed); model endpoints open only after a first top-up, so the $5 mainly covers the data APIs. An @yepapi/mcp server and llms.txt let it plug into Claude Code or Cursor as an MCP tool.

Conditions

One $5 credit per account and no recurring free tier; model endpoints require a top-up first; the balance never expires but cannot be withdrawn; bulk multi-account sign-ups may be flagged as abuse.

Steps

  1. Sign in at app.yepapi.com with Google or GitHub
  2. Check the balance shows $5.00 and copy the key from Dashboard > API Keys
  3. Call a /v1 endpoint with x-api-key or Bearer, starting with a $0.01 SERP or scrape call
  4. Top up later if you want the LLM and media models

Watch out

The $5 is one-off and pay-per-call burns faster than a subscription; data endpoint quality and anti-bot stability vary by target; model endpoints need real money first, so $5 will not run a frontier LLM.
