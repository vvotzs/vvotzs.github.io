Highlight

A realtime search and page-fetch API for AI agents with 100,000 free requests per organisation per month and no card required. Overage is $4 per 1,000 requests (about $400 a month at list price), and an official MCP server plugs into Claude Code or Codex.

What you get

Keenable sells search and fetch to AI agents and says version 1.0 reached first place on the Artificial Analysis Search Index. Its pricing page, read on 2026-11-20, states every organisation gets 100,000 free requests a month with no credit card: create an API key in the console and the allowance is live. After that, pay-as-you-go is $4 per 1,000 requests, and labs or inference platforms at 100+ RPS pay $1 per 1,000 on dedicated capacity. One search or fetch is one credit, with search.realtime, search.pro, fetch and fetch.live all costing one credit each, and every response reports its own usage. The MCP server at api.keenable.ai/mcp and the CLI draw on the same allowance, and keyless use runs on a shared public pool of 1,000 requests per hour per IP.

Conditions

The allowance is 100,000 requests a month per organisation and resets on the day the organisation was created. An API key allows 10 requests per second with no hourly cap. Past the allowance, /v1/search returns 402 until credits are bought or the allowance resets. No card is needed for the free tier; buying credits or enabling auto top-up requires one. Academic and startup programs are separate applications.

Steps

  1. Open keenable.ai/pricing, choose Get Free 100K requests and create an organisation
  2. Create an API key in the console; no card required
  3. Run one /v1/search call using the quickstart at docs.keenable.ai
  4. For Claude Code or Codex, connect the MCP server at https://api.keenable.ai/mcp

Watch out

The allowance is per organisation, does not roll over and stops service with a 402 once used up. Result quality and any affiliate or sponsored links in results need checking before an agent relies on them. The terms state no end date, so the allowance could change at any time.
