Highlight

The official hosted API from the Crawl4AI team: verify an email and get a key with 1,000 credits a month and no card; a plain page costs 0.1 credit, a real-browser page 0.5 and a hard site 2, failed calls are free, and one key reaches 109 tools over 47 sites plus any web page

What you get

Crawl4AI is the open-source crawler with 87,000 GitHub stars, and its official Cloud version now includes 1,000 free credits every month: verifying an email issues an API key without a card. Credits are spent per call, with a plain page at 0.1 credit, a page needing a real browser at 0.5 and a hard site at 2, and failed calls are not charged, so the monthly grant covers roughly 10,000 plain pages. Rate limits are 10 requests a minute with two in flight. One key reaches 109 tools: scraping and structured extraction from any page, listing a whole site and crawling it level by level, its own search plus Google's results page, Google Maps and reviews, the Meta ad library, and structured rows from 47 sites including YouTube, Amazon, Reddit, GitHub and Hacker News, all also usable as an MCP server inside an agent. The team says Cloud is in soft launch, so prices and the free grant can change; self-hosting the open-source crawler removes the limits.

Conditions

An email verification issues the key; the free grant is 1,000 credits a month at 10 requests a minute and 2 concurrent; prices and the grant can change during the soft launch; scraping third-party sites is the caller's responsibility under robots rules and local law.

Steps

  1. Open crawl4ai.com and verify an email to get a free API key
  2. Put the key into the API calls or the MCP server
  3. Scrape one plain page (0.1 credit) to confirm the grant and the output

Watch out

Prices and the free grant may change while Cloud is in soft launch; the grant resets monthly and does not accumulate; the rate limit is low, so bulk scraping needs a queue or self-hosting; scraping other people's sites carries compliance duties; SOC 2 is still in progress, targeted for January 2027.
