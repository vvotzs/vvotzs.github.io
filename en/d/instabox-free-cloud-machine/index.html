Highlight

One Firecracker microVM per agent, Debian 13 with a desktop and Chromium, pausing after 30 idle minutes and resuming in under a second at $0.

What you get

InstaBox gives each AI agent its own cloud Linux machine: a Firecracker microVM on Debian 13, by default 4 vCPU and 8 GiB of RAM, a 16 GiB root disk plus a 20 GiB persistent disk at /data, with Chromium, a desktop, Docker, Node.js, Python, Go, Rust and Claude Code, Codex and OpenCode already installed. Logins persist in /data/home and travel into snapshots. The free tier is $0: one machine, five snapshots, 100 GiB egress a month, auto-pause after 30 idle minutes with state kept and no billing while paused, and runs capped at 120 minutes at first, growing to 480 with use. The pricing post says the free machine has no usage limit; it is built for bursty agent work rather than a 24/7 server. Sign-up is GitHub or Google, and npx instabox@latest sh installs the CLI and starts a machine; the dashboard can also create one with a click and open its desktop.

Conditions

Free plan: 1 machine, 5 snapshots, 100 GiB egress/month, auto-pause after 30 idle minutes, 120-minute runs to start. Whether a brand-new free account needs a card is not stated (the API has a cardMissing state — unverified). US regions only.

Steps

  1. Sign in at instabox.sh with GitHub or Google and create a free machine from a template
  2. Open the machine desktop, or connect with npx instabox@latest sh
  3. Run Claude Code / Codex with your own model keys; let it pause when the task ends

Watch out

It pauses when idle, so it is not a always-on server. GitHub, Claude and Codex logins live inside the machine and travel into snapshots. US-only nodes mean high latency from Asia.
