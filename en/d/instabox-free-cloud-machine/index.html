One Firecracker microVM per agent, Debian 13 with a desktop and Chromium, pausing after 30 idle minutes and resuming in under a second at $0.

What you get

Each AI agent gets its own cloud Linux machine: a Firecracker microVM on Debian 13 with 4 vCPU, 8 GiB of RAM, a 16 GiB root disk and a 20 GiB persistent disk at /data, preinstalled with Chromium, a desktop, Docker, Node.js, Python, Go, Rust and the Claude Code, Codex and OpenCode agents, with login state in /data/home that travels between machines. Free costs $0 for one machine, five snapshots and 100 GiB of egress a month, pausing after 30 idle minutes with state kept and nothing billed, running up to 120 minutes at a time extended to 480 with use; InstaBox says free machines have no uptime cap and simply pause when off, designed for bursty agent work. Sign in with GitHub or Google, run npx instabox@latest sh for the CLI, or create machines in the web console, and free machines start only from the agent-browser, android, omarchy and ci templates.

Conditions

Free means one machine, five snapshots, 100 GiB of egress a month, a 30-minute idle pause and 120-minute sessions; whether a new free account needs a card is unstated (the API has a cardMissing state, unverified); machines are US-only.

Steps

  1. Sign in at instabox.sh with GitHub or Google and create a free machine from a template
  2. Open the machine desktop, or connect with npx instabox@latest sh
  3. Run Claude Code / Codex with your own model keys; let it pause when the task ends

Watch out

It pauses when idle, so it is not a always-on server. GitHub, Claude and Codex logins live inside the machine and travel into snapshots. US-only nodes mean high latency from Asia.
