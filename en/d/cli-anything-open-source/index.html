Highlight

From HKUDS: generates command-line harnesses for CAD, 3D, Office and other software so Claude Code or Codex can call them; install via CLI-Hub, Apache-2.0 licensed

What you get

CLI-Anything, maintained by HKUDS, turns desktop software into command-line interfaces that agents such as Claude Code and Codex can call directly. The repository ships harnesses for individual applications plus a unified entry point, CLI-Hub (pip install cli-anything-hub, then cli-hub install). It is Apache-2.0 licensed, created in March 2026, and now has 65k stars and 312 open issues with active community contributions. You can also write your own harness and open a PR, which is reviewed and added to the hub.

Conditions

Needs Python and pip; some harnesses require the host application or its licence; it is a local tool with no cloud credits or compute.

Steps

  1. Clone the repository or pip install cli-anything-hub
  2. Use cli-hub to search for the target software and install its harness
  3. Add the generated CLI to your Claude Code or Codex configuration
  4. Run the examples in the repository and check the output

Watch out

It moves fast with many open issues, so interfaces and harnesses can change; third-party harnesses in CLI-Hub are not individually audited, so read the code before running it; some applications need a valid licence to work.
