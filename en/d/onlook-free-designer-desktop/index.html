Highlight

Design on top of your real codebase: Onlook overlays a canvas on your repo, and clicking an element and saying 'make this a card layout' drives the Claude Code or Codex you already run to produce a git diff or PR. The desktop app is free and open source.

What you get

Onlook (YC W25) launched on Hacker News on 2026-11-19, announcing it had rebuilt the product as an agentic design tool and open-sourced the whole thing under Apache-2.0. The desktop app is an Electron program: import a GitHub repo or a local folder and it creates a git worktree, starts the dev server and has the agent sort out dependencies. You select elements on the canvas and give instructions; changes appear as git diffs you can push as a PR or throw away, and several worktrees can run at once. Onlook does not train its own model. It runs your existing Claude Code or Codex subscription, turns whatever the agent emits into one typed event log, and renders the UI from that. It adds design-specific tools such as arranging frames on the canvas and generating several iterations of a selection. The desktop editor is free and open source; a paid cloud product for teams is planned, along with image, vector and font generation. The project has had 25,000+ designers and developers, 100+ contributors and two stints as the world's trending #1 repo.

Conditions

Free and open source, but you need your own working Claude Code or Codex subscription because Onlook supplies no model credits. The desktop app is aimed at macOS and Windows (Linux is not officially offered yet). The imported repo needs a dev server that starts, or the canvas cannot boot.

Steps

  1. Download the desktop app from onlook.com, or build it from github.com/onlook-dev/onlook
  2. Import a project from GitHub or a local folder and let it create the worktree and start the dev server
  3. Select elements on the canvas and give instructions; the agent edits code through your own Claude Code or Codex
  4. Review the diff and open a PR or discard it

Watch out

The tool is free but model usage comes out of your own subscription. It is early software, so complex repos may fail to start. When cloud collaboration and image, vector or font generation ship as paid features, the free boundary may narrow.
