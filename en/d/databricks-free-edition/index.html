Highlight

Databricks Free Edition is free to sign up for and covers notebooks, the in-product AI assistant, agent building, model training and API serving, ETL pipelines, Genie natural-language BI and the Academy courses. The official FAQ calls it free for all users and perpetually free, restricted to personal, non-commercial use.

What you get

Databricks' free data and AI platform, an expansion of Community Edition: one workspace builds Python and SQL notebooks, writes code with the built-in Assistant, assembles LLM agents and knowledge-base Q&A, trains classic ML models and serves them as APIs, runs ETL pipelines with schema-drift and data-quality checks, and uses Genie to question data in plain language and build dashboards. The FAQ says it is free and permanent for all users at the cost of smaller compute and warehouse sizes under fair use, limited to personal learning rather than production or commercial work, with Community Edition continuing this year before migration. Academy courses and training are free too. It is not an SSH-able cloud host and has no dedicated IP or ports.

Conditions

Personal learning and non-commercial use only, with commercial use against the terms; small compute and warehouse sizes under fair use; Community Edition works this year before migration; the workspace is managed, so no SSH, dedicated IP or ports.

Steps

  1. Open databricks.com/learn/free-edition and start free
  2. Sign up with an email, create a workspace and run a first Python or SQL notebook
  3. To try agents, build a knowledge-base Q&A or a model serving endpoint in the workspace
  4. Take the free Databricks Academy courses; limits follow what the workspace shows

Watch out

Commercial use is not allowed and can get the account suspended; clusters are small and quota-bound, so large model training queues or gets cut off; the vendor can adjust limits and terms at any time; it is not a general cloud host, so proxies and VPNs are out.
