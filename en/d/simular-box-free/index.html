Highlight

Sign up for 5,000 credits (1,000 credits = $1) and give an AI a real cloud Linux desktop: it can open a browser, click, read the screen and run commands

What you get

box is Simular's cloud Linux desktop; connected to an AI client as a remote MCP server, the AI can really open a browser, click, type, read the screen and run commands. Each account gets one desktop, which sleeps when idle; the free tier gives 5,000 credits one-off (1,000 credits = $1, about 50 hours of box time, valid 90 days), and the paid tiers are S at $19/mo and M at $39/mo (M doesn't sleep). A box asleep for 14 consecutive days is deleted.

Conditions

Register a Simular account and authorise the MCP server via OAuth; the 5,000 free credits are one-off and valid 90 days; the AI itself still needs its own subscription or API; free boxes sleep when idle and are deleted after 14 days without waking.

Steps

  1. Register and sign in at box.simular.ai
  2. Add https://mcp.box.simular.ai/mcp as a remote MCP server in your AI client
  3. Authorise with your Simular account on the first connection
  4. Let the AI run tasks on the cloud desktop (open a browser, run commands, edit files)

Watch out

Beyond the free credits it's billed per credit, so don't let the AI spin idle; the desktop holds your browser session, so don't sign into important accounts inside it.
