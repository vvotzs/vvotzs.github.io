# ads.txt — 羊毛情报局 / Deal Hunter (https://vvotzs.github.io/)
#
# 用法：在 Google AdSense 后台拿到自己的发布商 ID（形如 pub-0000000000000000，
# 也就是 ca-pub-… 去掉 ca- 前缀）后，把下面「示例行」开头的 # 去掉并替换 ID 即可。
# 一行一条记录，格式固定：<广告系统域名>, <发布商 ID>, <关系>, <认证机构 ID>。
#
# 现在站内还没有接入广告：这里只有注释、没有任何有效记录，所以是合法且空的 ads.txt，
# AdSense 后台只会显示「未找到记录 / 待添加」，不会因为格式报错。
#
# 示例行（换成自己的 ID 后取消注释）：
# google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0
