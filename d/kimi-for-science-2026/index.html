亮点

面向自然科学、工程学及交叉学科的科研人员与团队，按研究需求评审发额度：最高 15 万元 Kimi API（约 70 亿 tokens，不是现金），另给技术支持、新模型优先体验与长期合作机会；首期 12/8 截止，可多次提交以最后一次为准

优惠内容

月之暗面 11/26 开放 Kimi for Science 首期申请，支持三类探索：用 Kimi 改进现有研究流程、尝试新研究方法、攻更具挑战的科学问题。入选者按研究需求与评审结果拿最高 15 万元 Kimi API 调用额度（官方折算约 70 亿 tokens，非现金资助），并获 Kimi 团队技术支持、新模型优先体验与精选研究／社区资源，优秀团队还有长期合作机会。申请建议准备研究者信息、研究任务、数据来源、当前工作流、Kimi 使用方式与验证指标，token 估算与里程碑按需补充。首期 12/8 截止，之后还会开更多批次，多次提交以最后一次为准。

参与条件

首期仅限自然科学、工程学及相关交叉学科科研人员／团队；需在线填写研究任务、数据来源、现有工作流与用量说明；12/8 前提交，可多次提交以最后一次为准；结果发到申请邮箱，是否入选与额度以评审为准。

参与步骤

  1. 打开 kimi.com/news/kimi-for-science-program 的申请入口
  2. 准备研究者信息、研究任务、数据来源、现有工作流、Kimi 用法与验证指标
  3. 在线填写并在 12/8 前提交，需要改动就再提交一次
  4. 等邮件评审结果，入选后按分配额度接入 API

风险提示

评审制，普通用户拿不到；额度是 API 调用而非现金，不能提现；申请要写清研究计划，敷衍填写基本不会入选；首期名额与后续批次时间未公布。
