亮点

MCP 服务器与命令行 gwscli 于 2026-11-24 转正式版；Standard 档不要结算账号、不要信用卡，8 款 GA 应用各 5,000 次/天，超了只限流不出账

优惠内容

2026-11-24 Google 把 Workspace MCP 服务器与官方命令行 gwscli 转为正式版（GA），两周内推给所有用户。8 款 GA 应用是 Gmail、Drive、Docs、Sheets、Slides、Calendar、Chat、Tasks，Keep 即将加入。默认 Standard 档完全免费：每项目、每款产品每天 5,000 次请求（另有每分钟限速），不需要 Cloud 结算账号或信用卡，8 款合计单项目一天可到 4 万次；超了只限流等配额重置，不会产生账单。网页与云端 AI 直连远端 MCP，本地终端或沙箱里的智能体用 gwscli，自带打包技能、动态命令发现与分范围登录。

参与条件

个人 Google 账号即可，Standard 档免结算账号与信用卡；额度按 Cloud 项目计，个别 MCP 工具一次调用会算多次请求；2027-02-01 起 AI 智能体必须走 MCP，直调 REST 只能拿 Standard 配额；切到 Scaled 档会撤掉 MCP 的每日免费额度。

网页端

参与步骤

  1. 在 Google Cloud 控制台启用需要的 Workspace MCP 服务（gmailmcp/calendarmcp/drivemcp 等 8 个域名之一）
  2. 保持项目在默认 Standard 档，不关联结算账号
  3. 云端或网页 AI 直接连远端 MCP 地址授权；本地终端智能体装官方 gwscli
  4. 在 Cloud 控制台的 API 配额看板核对每日用量，别把单次对话当成单次请求

风险提示

额度按 Cloud 项目算而非按账号，8 款应用各自独立；一次工具调用可能计多次请求，别按对话次数估额度。2027-02-01 起直调 REST 的智能体被压回 Standard 配额，2027-04-01 起 Scaled 档的 Gmail/Calendar/Drive MCP 从第 1 次请求计费，为提额随手切 Scaled 档会直接开始花钱。MCP/CLI 取的是本人 Workspace 数据，授权范围与第三方共享要自己看清。
