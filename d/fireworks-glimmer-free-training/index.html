优惠内容

Fireworks 官方博客《Train Muse Glimmer for free》宣布 Free Weights Club 首期活动：Muse Glimmer 30B（多模态、30B 量级）在 2026-11-30 前用监督微调（SFT）、DPO 与 RL 训练全部免费，无需信用卡，可用 Managed Training（网页端或 API）跑 SFT，也可用 Serverless Training API 自己写训练循环。官方文档与 cookbook 另有一句补充：LoRA SFT 在 UI 与 Serverless Training API 上免费，仅对 `2026-12-01T00:00:00-08:00` 之前启动的 LoRA SFT 任务生效，脚本默认拒绝在该时间之后启动（除非加 `--allow-paid`）。 官方给的样板实验：用 Kalshi 预测题的 cookbook 训练一轮 LoRA，在未见过的题目上把准确率从 base 的 53.2% 提到 58.3%，比对照组 Jev 高 11.2 个百分点。训练产物是 LoRA adapter，可以 promote 成模型，但要对外提供服务仍需 on-demand 部署（按 GPU 小时计费）。

参与条件

注册 Fireworks 账号，免绑卡；免费只覆盖「训练」——推理、包括训练中的评估采样都按 token 单独计费；Serverless 上 Muse Glimmer 30B 自 2026-09-25 起已下架，服务调优后的模型需要 on-demand 部署；博客写 SFT/DPO/RL 全免，但 cookbook 只明确 LoRA SFT 免费，DPO/RL 请以任务创建页的计费提示为准。

参与步骤

  1. 注册 Fireworks 账号（免绑卡）
  2. 在 Managed Training 或 Serverless Training API 里选 `accounts/fireworks/models/muse-glimmer-30b`
  3. 准备 chat JSONL 数据，启动 LoRA SFT（可用官方 cookbook 的 muse_glimmer starter）
  4. 看 launch 打印的采样 token 费用行，确认只有评估采样计费
  5. 把训练好的 LoRA promote 成模型；要对外服务再开 on-demand 部署

风险提示

只免训练，推理和评估采样照价收费，跑大评估集会出账单；训练完要上线还得按 GPU 小时部署；博客与文档对 DPO/RL 是否覆盖口径不一致；11-30 之后启动的任务不再免费。
