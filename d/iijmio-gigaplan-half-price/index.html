优惠内容

IIJ 在 2026-11-05 开跑「IIJmioギガプラン半額キャンペーン」，结束日未定。对象是 IIJmio ギガプラン 的「音声SIM」或「音声eSIM」，容量 5/10/15/25/35GB，新规、MNP 转入或从旧套餐（ミニマムスタート、ライトスタート、ファミリーシェア、従量制等）改到ギガプラン 都算：开通后第 1–3 个月，月租按档直减——5GB 475 円、10GB 700 円、15GB 800 円、25GB 1,000 円、35GB 1,200 円（税込）。选 15GB 的还额外送 5GB×最多 3 个月（即 20GB 用 3 个月）。同期还有「通話定額オプション割引キャンペーン」（通話定額 5 分+ / 10 分+ / かけ放題+ 最多 3 个月 0 円），两个叠加后：15GB（20GB）+ かけ放題コミ 20GB 组合约 800 円/月（家族割引 700 円）。首月按月内天数日割，折扣以当月账单为上限、不结转。

参与条件

须在活动期内申请 5/10/15/25/35GB 的 音声SIM 或 音声eSIM 并完成开通；开通后须保持同一容量档到特典结束，中途改容量、改成数据/SMS 专用 SIM、解约即失去折扣（SIM⇄eSIM 形状变更可继续）；25GB 用本活动后不能再叠加「25ギガプランお試し割」；BIC SIM、JAL モバイル 渠道、以及已在用ギガプラン 的单纯容量变更不适用；首月日割时折扣不超过账单金额。

参与步骤

  1. 在 iijmio.jp 选 ギガプラン，SIM 形态选「音声eSIM」或「音声SIM」，容量选 5/10/15/25/35GB
  2. 新规或 MNP 转入（或在 My IIJmio 里从旧套餐改到ギガプラン），按页面提示完成本人确认与支付方式
  3. 收到 eSIM 开通二维码后激活；折扣自动从开通当月算第 1 个月起适用，无需另申请
  4. 想再省通话费，同时勾选「通話定額オプション」（活动期内最多 3 个月 0 円）
  5. 保持同一容量到 3 个月期满；之后按原价（5GB 950 / 10GB 1,400 / 15GB 1,600 / 25GB 2,000 / 35GB 2,400 円）继续

风险提示

需要日本地址、日本支付方式与本人确认，海外用户基本办不了；结束日未定，可能随时收；折扣只有 3 个月，第 4 个月起回原价，长期成本要自己算；中途改容量或换 SIM 功能即失去折扣；首月日割可能让折扣「看不见」。
