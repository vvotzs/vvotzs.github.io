亮点

一个 MCP 网关接上 1,100+ 连接器、5.5 万+ 工具（Salesforce、GitHub、Slack、Google Drive…），agent 以「提问的那个人」的身份、在你授予的范围内执行；免费层含每月 1 万次工具调用与 1 万次触发器事件。

优惠内容

Scalekit 的 AgentKit 是给「要上生产的 agent」用的 MCP 网关（Product Hunt 2026-11 月榜第 6）：把 Salesforce、GitHub、Slack、Google Drive 等 1,100+ 连接器、5.5 万+ 工具收进一个网关，AgentKit 负责 OAuth 与集成，每个动作都以发起请求的那个用户的身份、在那个用户授予的 scope 内执行；用 Virtual MCP Servers 只给每个 agent 它需要的工具；Custom connectors 可把内部 API 接进来；Triggers 能在邮件到达的瞬间启动 agent；每次调用都有日志。定价页的 Free 档是 $0/月：每月 10,000 次工具调用、10,000 次触发器事件、不限连接账号、1,100+ 连接器与 5.5 万+ 工具、自带凭据（bring your own credentials）、社区与邮件支持。Growth $99/月：10 万次调用 + 超出 $0.50/1K，5 万次事件 + $3/1K。

参与条件

免费层要自带各家服务的 OAuth 凭据（Scalekit 不代你申请）；额度按自然月重置；超出免费额度要升 Growth（$99/月起）或按量付费；企业功能（SSO、SCIM、BYOK、HIPAA BAA、VPC/on-prem）只在 Enterprise。

参与步骤

  1. 在 scalekit.com 注册开发者账号并创建 environment
  2. 在 dashboard 里选要开放的连接器（GitHub、Slack、Google Drive…），填入自己的 OAuth 凭据
  3. 建一个 Virtual MCP Server，只挂这个 agent 需要的工具，拿到 MCP 地址
  4. 把地址填进 Claude / Cursor / 自建 agent，按用户授权跑通一次调用
  5. 在用量页盯住 10,000 次/月的免费额度，接近上限再决定是否升 Growth

风险提示

官方页面自相矛盾：Free 卡片写「10,000 tool calls / mo」，同页对比表 Free 一列写「Tool calls / month 5K」，两个数字不一致，以注册后控制台显示为准（待核实）；免费层要自己申请并维护各家 OAuth 凭据，不是开箱即用；超出后按 $0.50/1K 计费，量大时账单会跑得很快。
