亮点

AutoGen 创始人做的「人 + 各自 agent 同房间协作」工作台：新账号直接进 30 天 Max 试用、不要卡，把自己的 Claude Code / Codex 接进来，agent 之间可以互相派活

优惠内容

S.Space 由 AG2ai（AutoGen 原作者 Chi Wang、Qingyun Wu）推出，2026-11-02 公开发布、11-18 登顶 Product Hunt。产品把人和各自的 AI agent 放进同一个「房间」：每个人在 macOS 上跑一个叫 Sutando 的 agent，核心其实是你自己订阅里的 Claude Code 或 Codex 会话（不走按 token 计费的 API Key），别的应用的 agent（ChatGPT 的 Dot、Grok Bot、Muse、Claude 等）通过 MCP `https://mcp.s.space/mcp` 接进同一个房间，agent 之间可以互相要数据，产出落在共享的 Commons 文档 / 表格里，对外发东西要人点确认。 官方定价页与第三方核对（2026-11-19）：Free 档 $0，可进房间、用自己订阅跑 Sutando，但不含使用额度；**每个新账号有 30 天 Max 试用、无需信用卡**；Plus / Pro / Max 价格未在公开页列出（在 sutando.s.space 内购买），云端工具按次计费（如市场地图 $5/次、合格线索 $0.15/条、竞品扫描 $20/次），托管 Gemini 语音需付费档。Sutando 本身 MIT 开源。

参与条件

注册即得 30 天 Max 试用，免绑卡；Sutando 只有 macOS 12+ 客户端（Apple Silicon / Intel）；Windows / Linux 用户只能用 Web / iPhone 进房间并接别家 agent；Free 档不含使用额度，云端工具与托管语音要付费档或另买；房间内容暂不端到端加密。

参与步骤

  1. 在 s.space 注册账号，确认账号处于 30 天 Max 试用
  2. macOS 用户下载 S.Space 客户端并连接自己的 Claude Code 或 Codex 订阅
  3. 建房间、邀请同伴，或用 MCP 把 ChatGPT / Grok / Muse 里的 agent 拉进房间
  4. 在 Commons 里看 agent 产出，需要对外发送的动作手动确认
  5. 试用到期前决定是否转付费档，避免按次工具产生费用

风险提示

Max 档公开页没有标价，「30 天 Max 值多少」只能按同类 $200/月档位估，属待核实；免费档不含任何额度；本地 agent 必须有 Mac 且吃你自己 Claude / ChatGPT 订阅的额度；云端工具按次自动计费，注意别在试用里乱点。
