亮点

Pro $100/$200/$500 档每月分别送等额 API credits，Business 按付费席位算（Standard $20/席、Premium $100/席），封顶 $500/工作区

优惠内容

OpenAI 官方文档：符合条件的 ChatGPT Pro 与 Business 付费订阅可领取免费 API credits——Pro 100/200/500 三档每月分别给 $100/$200/$500；Business 按付费席位计算（Standard $20/席、Premium $100/席），每工作区每月封顶 $500（年付一次性发放全年、封顶 $6,000）。在 ChatGPT 设置 → 账单里把订阅绑定到自己拥有的 API 组织即可激活，之后每个计费周期自动续发；额度可用于 Responses、Agents、Decisions、Realtime、Images 及内置工具等 API 费用，Codex 用 API Key 的消耗不适用。

参与条件

需付费 Pro 或 Business 满 7 天；必须是订阅/工作区所有者和 API 组织所有者，且两边邮箱一致；Free/Plus/Go、免费试用、Enterprise、Edu、旧 Codex 席位不含；额度按计费周期清零、不结转；首个周期按剩余天数折算；部分国家/用户群未开放。

参与步骤

  1. 用持有 Pro/Business 订阅的账号登录 ChatGPT
  2. Pro 进「设置 → 账单」，Business 进工作区账单设置，找到 API credits 权益
  3. 选择要接收额度的 API 组织并确认绑定
  4. 到 API Platform 的 Billing 页面确认额度到账，再用该组织的 Key 调用

风险提示

要先付 $100/月起订阅费，本身不是免费；额度当月不用就作废；首个周期可能只按剩余天数折算；不提升 ChatGPT 与 Codex 的使用上限；账号或国家不在灰度范围就看不到入口。
