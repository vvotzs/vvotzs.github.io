优惠内容

Kiro（AWS 的 agentic IDE）从 2026-03 起做 Kiro Students，2026-10-28 又扩了 41 所学校，现在名单里有 133 所大学（美国 ASU、CMU、加州州立多校，英国 City of Glasgow College，印尼 Binus，以及新增的澳洲、印度、欧洲院校等）。条款写明：符合条件的在校生可拿 1 年权益，按月发放 1,000 credits，共 12 个月。 权限等同付费档：可用 premium models、Kiro Web 与 Kiro Crew，不只是免费版的 5 个 open-weight 模型。SheerID 认证一次通过后账号档位直接变成 Kiro Students，不需要信用卡、没有试用计时器；满一年后自动降回 Kiro Free，代码和 spec 都留在本地与仓库里。

参与条件

必须是在读学生且学校在官方下拉列表内，年满 18 岁；SheerID 需填姓名、生日、学校邮箱，可能补传学生证或在读证明；认证一辈子只能做一次，信息别填错；每月 credits 不累计、当月用不完清零，也不能额外买加量包；一年后自动降级为免费档。

参与步骤

  1. 用 Google / GitHub / AWS Builder ID 登录 kiro.dev（不要走「Your organization」入口）
  2. 进 Settings → Students，选自己的学校并点 verify
  3. 按 SheerID 提示填姓名、生日、学校邮箱，必要时上传学生证或在读证明
  4. 看到档位变成 Kiro Students 后，当月 1,000 credits 立即可用

风险提示

学校不在名单里就没有入口，只能填兴趣表等扩展；一个月 1,000 credits 用超了要等下个周期，不能买加量；认证一旦失败或填错学校，很难重新认证；需要有真实的在读身份，代认证属于违规。
