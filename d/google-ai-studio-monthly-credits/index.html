亮点

2026-11-13 起，Google AI Pro / Ultra 订阅者可在 AI Studio 里直接创建开发者档案、绑定结算并领取每月 Google Cloud 额度：Pro $10/月，Ultra(5×) $40/月，Ultra(20×) $100/月，每笔 12 个月内有效且可逐月累积，用于 Gemini API（含 Gemini 4 Carbon 等付费档模型）

优惠内容

Google 官方博客（2026-11-13）与开发者计划权益/FAQ 文档（duckssi 2026-11-18 整理核对）：过去要在多个站点间跳转领取的月度云额度，现已内置到 AI Studio 左侧菜单。额度按订阅档位发放（Pro $10、Ultra 5× $40、Ultra 20× $100），每笔自发放日起 12 个月有效并逐月叠加；不回溯——只有建好开发者档案之后的月份才发。要在 Gemini API 上花这些额度，需先预充至少 $5 余额；额度按最早到期优先扣。付费档模型（如 Gemini 4 Carbon）正好用得上。

参与条件

需为 Google AI Pro / Ultra 订阅人并在 AI Studio 建好 Google Developer Program 档案；额度仅主订阅人可用、不可家庭共享；不回溯此前月份；用 Gemini API 需先预充 ≥$5 并保持余额；每笔额度 12 个月有效，按最早到期先扣；免费版开发者计划无月度额度。

参与步骤

  1. 用订阅 Google AI Pro / Ultra 的账号打开 Google AI Studio
  2. 左侧菜单进入额度页，创建/关联 Google Developer Program 档案
  3. 绑定 Cloud 结算账号并领取当月额度
  4. 如需调用 Gemini API，先预充 ≥$5
  5. 每月回 AI Studio 领取新一笔，注意 12 个月到期顺序

风险提示

本质是订阅附带的额度，要算清订阅成本；此前月份不补发，早订阅晚建档等于白丢；必须预充 $5 才能扣额度；Gemini API 已从 $300 试用额度适用范围里被移出（2026-11-16 起）。
