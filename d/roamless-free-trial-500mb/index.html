优惠内容

Roamless 是「一张全球 eSIM + 按量付费」的模式：新用户安装并激活 eSIM 后，账户自动到账 $1.25 的按量付费额度，按目的地单价折算约 500MB（便宜的国家的能换更多），不用绑卡、不用先充值，额度不过期，之后 200+ 目的地继续用同一张卡扣费。付费按量约 $1.95/GB 起，也有固定流量包（约 $0.58/GB 起）。

参与条件

仅限 Roamless 新用户，一个账号/设备一次；需下载 App、注册并安装 eSIM；免费额度在激活 eSIM 后自动到账；少数目的地不开放免费额度。

参与步骤

  1. 从 App Store / Google Play 下载 Roamless 并注册（邮箱或 Google / Apple / Facebook 登录）
  2. 在首页点 Install eSIM，安装 Roamless eSIM
  3. 按提示设置移动数据线路
  4. 激活后 $1.25 额度自动到账，在余额里能看到

风险提示

500MB 是按 $1.25 折算的上限，单价高的目的地（如加拿大）换到的流量更少；额度用完不会自动停，余额不足就断网；这是按量付费产品，后续容易顺手充值。
