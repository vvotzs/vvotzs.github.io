优惠内容

InstaBox 给每个 AI 代理一台独立的云端 Linux 机器：Firecracker microVM，Debian 13，默认 4 vCPU / 8 GiB 内存、16 GiB 根盘加 20 GiB 持久盘（挂 /data），预装 Chromium、桌面环境、Docker、Node.js、Python、Go、Rust，以及 Claude Code、Codex、OpenCode 三套编码代理，登录信息存在 /data/home 里可以跨机器带走。 免费档 $0 就能用：1 台机器、5 个快照、每月 100 GiB 出网，闲置 30 分钟自动暂停（状态保留、不计费），单次运行最长 120 分钟并按使用情况逐步放宽到 480 分钟。官方明确说免费机器没有使用时长上限，关掉就暂停，是给「突发式代理任务」设计的，所以不像 VPS 那样 24 小时烧 CPU。 开通只要 GitHub 或 Google 账号，npx instabox@latest sh 一条命令就能装 CLI 并起机器，也可以直接在网页控制台点按钮建机器、开桌面、开端口。

参与条件

免费版 1 台机器、5 个快照、100 GiB 出网/月、闲置 30 分钟暂停、单次运行 120 分钟起；新建免费账号是否需要绑卡官方未写明（API 有 cardMissing 状态，待核实）；机器只在美国。

参与步骤

  1. 用 GitHub 或 Google 登录 instabox.sh，在控制台按模板创建一台免费机器
  2. 进入机器桌面或用 npx instabox@latest sh 连上 CLI
  3. 在机器里跑 Claude Code / Codex（用你自己的模型 Key），任务结束让它自动暂停

风险提示

免费机器闲置即暂停，不能当常驻服务器；机器里存着 GitHub / Claude / Codex 登录态，做快照会一并带走；只有美国节点，国内直连延迟偏高。
