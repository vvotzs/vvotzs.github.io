优惠内容

Tesseract 是 Eightcell Labs 出的免费桌面 AI 代理，2026-11-14 在 Product Hunt 首发。它不做聊天，而是直接交付成品：说一句「给我的面包店做一份投资人 PPT」，它先给计划、再动手，最后交出可以继续编辑的 PowerPoint / PDF；同样的流程还能出网站（220+ 模板、14 套主题）、Logo 与品牌套件、字体、视频、表格和调研报告，文件都直接落在你的电脑上。 收费方式很关键：它不卖订阅、不卖 credits，而是复用你已有的 AI 订阅——Claude Code、Codex、Gemini CLI、OpenCode、Cursor Agent、Kimi Code、Qwen Code 等十几种代理都支持，登录你自己的账号即可；官方写明「有 Claude 或 ChatGPT 订阅时，用多少都不额外计费」。一个账号额度用尽会自动切到下一个账号。完全没有 AI 订阅的人可以先走内置免费额度，额度会补充，需要更多再按 $10 起预付。

参与条件

彻底免费的前提是你已有 Claude / ChatGPT 等订阅（额度仍受该订阅自身限制）；没有订阅时只能用官方免费额度，次数未公布（待核实）；不提供手机端。

参与步骤

  1. 到 tesseract.dev 下载对应系统版本（无需信用卡）
  2. 首次打开时选择已在用的代理并登录自己的账号，或直接使用免费额度
  3. 在首页 33 个引导模板里挑一个，或直接一句话描述需求，等它交付可编辑文件

风险提示

免费额度具体次数官方未公布；桌面代理会读写本机文件与剪贴板，建议先在空目录试跑；依赖的第三方代理 CLI 可能需要额外授权。
