亮点

大学研究型教职或博后 11/23 起先到先得申请，一份覆盖本人 + 2 名同校合作者（研究生可当合作者）各一个 Plus 席位、免费 12 个月，不含 API 额度

优惠内容

项目目标是覆盖20万名研究者，下一轮申请11-23（周一）开放5万份，按申请先后先到先得、不再抽签。每份覆盖申请人+最多2名同校合作者，共3个ChatGPT Plus席位、免费用12个月；本轮由试点的Pro换成Plus（官方称多数试点用量在Plus限额内）。独立研究workspace、默认不用项目数据训练模型，含培训，不含API额度；已在候选名单者开放前会收到激活邮件。

参与条件

须为合资格院校的研究型教职或博士后，近三年在生物、化学材料、计算机、地球行星、工程、数学、物理发表过论文；合作者须同校并用学校邮箱验证，研究生可当合作者但不能独立申请；中国大陆与香港不在范围；名额按申请顺序发完即止；3席同一到期日，晚加入不重算12个月；开通时若出现非$0付款页先别确认。

参与步骤

  1. 准备好学校邮箱与近三年论文信息（期刊或会议均可）
  2. 11/23 当天从 OpenAI 官方公告页的项目入口申请，用学校邮箱登录 ChatGPT
  3. 按提示完成 SheerID 身份验证（邮箱须与申请一致）
  4. 获批后建立 Academic Researcher workspace，在设置里邀请 2 名同校合作者

风险提示

学生不能自己申请，只能被导师或博后加成合作者；5 万份先到先得，开放当天可能很快抢完；帮助中心目前仍写「申请已关闭、只收 waitlist」，以 11/23 实际开放为准；一份 3 席同日到期；到期前会问是否续用，别在非 $0 页面误付款。
