亮点

把「得打个电话」的事交给 ChatGPT / Claude / Muse / Claude Code：它先出通话计划，你确认后拨真实美加号码，穿过语音菜单与等待，回传摘要、逐字稿和结构化结果。

优惠内容

CALL-E 是 AI Rudder（新加坡）在 2026-11 推出的「打电话」代理：它只做外呼。你在已有的 AI 助手里（ChatGPT、Claude、Muse、OpenClaw、Hermes 等）或编码 agent（Claude Code、Codex、Cursor）装上官方 calle skill，或走 MCP / TypeScript、Python SDK / REST API / WhatsApp，说清楚要办的事，它就规划这通电话：打给谁、什么时间、用什么语言、办到什么程度算成功；缺信息会先问你，然后给出通话计划让你确认，确认后才拨号。接通后它处理真人应答、语音信箱、等待、转接、静音和插话，也能听语音菜单按键导航（IVR），结束后回传摘要、完整逐字稿，以及按你定义的 schema 校验过的结构化结果（带原文引证与完成度置信标签）。可以排程，也可以批量打给多个对象。典型用途：订位、改约、问报价、查库存、退订、找人工客服。新账号送 100 credits（官方说明约 US$1）；credits 是「用量额度」，不等于固定通话数或分钟数。

参与条件

新账号一次性 100 credits；按秒计费：美加外呼 Goal 模式约 $0.0148/10 秒模型费 + $0.02/分钟线路费（30 秒约 $0.06），一次性调用约 $0.0296/10 秒 + $0.04/分钟（30 秒约 $0.13）；准备阶段即使电话没接通也可能消耗模型 credits；只外呼，不接听、不筛来电；拨往美加以外的国际号码主要供开发测试，正式用需自备 SIP 线路。

参与步骤

  1. 在支持 MCP 的 AI 助手或编码 agent 里装上官方 calle skill（或直接用 API/SDK），登录后自动建立 CALL-E 账号与 100 credits
  2. 用日常语言说需求：「周五 19 点两人位，订在 Bella's Bistro，问有没有停车位」
  3. 它补齐缺失信息（打给谁、你的名字、什么算办成），给出通话计划让你确认
  4. 确认后它拨号、按键导航语音菜单、等待接通，通话中可以随时接手或追加指令
  5. 结束查看摘要、逐字稿和结构化结果；需要时可排程或批量外呼

风险提示

100 credits 只够少量试打，真正的代理体验要自己充值；计费=模型费+线路费，规划阶段没用上电话也可能扣额度；AI 会在电话里表明自己是助手，部分商家会拒接；涉及预约、退订、付款授权时务必先看清它的通话计划；中国大陆等地区能否注册与拨号以官网/登录页为准（待核实）。
