优惠内容

Keenable 是面向 AI agent 的搜索与抓取 API，官方宣称 1.0 版本登顶 Artificial Analysis Search Index。定价页（2026-11-20 核对）写明：每个组织每月 100,000 次免费请求，不用信用卡，注册后在控制台建 API Key 即可用；超出后按 $4 / 1,000 次计费，labs / 推理平台 100+ RPS 的专属容量 $1 / 1,000 次。一次请求按一个 credit 计，search.realtime、search.pro、fetch、fetch.live 都算 1 次，响应里会回传本次消耗。另有 MCP server（api.keenable.ai/mcp）与 CLI，走同一份额度；不建账号也能用共享公共池（每 IP 每小时 1,000 次、10 RPS）。

参与条件

免费额度 100,000 次/月，按组织计、每月在你创建组织的那一天重置；建 Key 后默认 10 RPS、无小时上限；用完后 /v1/search 返回 402，直到买额度或额度重置；不绑卡也能一直用免费额度，买额度或开自动充值才需要卡；学术项目可申请每月 10 万额外 credits，创业项目 $5,000 credits 需申请。

参与步骤

  1. 打开 keenable.ai/pricing 点 Get Free 100K requests，注册并建组织
  2. 在控制台创建 API Key（无需绑卡）
  3. 按 docs.keenable.ai 的 quickstart 调一次 /v1/search 验证额度
  4. 需要给 Claude Code / Codex 用时接 https://api.keenable.ai/mcp
