优惠内容

Vercel 2026-11-18 更新：AI Gateway 上的 Parallel 联网搜索 fast 模式免费开放到 2027-01-31，同时 Parallel 成为 eve agent 的默认搜索工具。Parallel 负责找相关网页并返回链接与短摘要，可按站点或发布日期过滤，支持任意 AI Gateway 模型，无需单独的 Parallel API Key。 代码侧用法：AI SDK 里把 `gateway.tools.parallelSearch({ mode: 'fast' })` 放进 tools；Chat Completions 则在 `vercel:parallel_search` 工具的 config 里写 `"mode": "fast"`；用 eve 时不用配置，默认就是 fast 且免费。 常规价格是 $5 / 1,000 次请求（每次最多 10 条结果，超出部分 $1 / 1,000 条），只有你在工具配置里写明 fast 才计 $0——模型自己在调用里挑了 fast 不算免费。免费额度是全站共享的，可能被限流，限流时模型会收到错误但请求不失败，也不会被改按付费重试。免费搜索不计入可计费的 gatewayToolCalls，但模型 token 照常收费。

参与条件

需要 Vercel 账号并在项目里启用 AI Gateway；只有工具配置中显式 `mode: 'fast'` 的搜索免费，basic / advanced / turbo 等模式照常 $5/千次；免费搜索会限流；2027-02-01 起 fast 模式恢复原价；ZDR 默认开启，Parallel 不保留免费搜索数据也不用于训练。

参与步骤

  1. 登录 Vercel，创建或打开项目并启用 AI Gateway Key
  2. 在 AI SDK 的 tools 里加入 gateway.tools.parallelSearch({ mode: 'fast' })（或 Chat Completions 的 config 写 mode: fast）
  3. 把工具交给任意 AI Gateway 模型调用，搜索按 $0 计费
  4. 在 AI Gateway 日志里核对搜索未被计费（token 仍计费）

风险提示
