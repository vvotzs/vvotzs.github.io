优惠内容

Onlook（YC W25）2026-11-19 在 Hacker News 发布 Launch HN，宣布把产品重建为 agentic 设计工具并整栈开源（Apache-2.0）。桌面应用是 Electron 程序：导入 GitHub repo 或本地文件夹后，它自己建 git worktree、起 dev server、让 agent 补齐依赖，你在画布上点选元素并下指令，改动都以 git diff 形式出现，可以直接推成 PR 或丢弃；同一项目可并行开多个 worktree。 Onlook 自己不训练模型，而是运行你已有的 Claude Code 或 Codex 订阅，把 agent 输出统一成带类型的事件流再渲染成右侧对话界面；此外给 agent 一套设计专用工具（画布上排布 frame、生成多个版本、给建议）。官方说明桌面编辑器免费、开源，未来团队版云协作收费（图片生成、矢量生成、字体生成等也在计划里）；25,000+ 设计师与开发者用过，100+ 贡献者，两次登上全球 trending 第一。

参与条件

免费、开源，需自备可用的 Claude Code 或 Codex 订阅（Onlook 不提供模型额度）；桌面端目前主打 macOS / Windows（Linux 未正式提供）；导入的仓库要有可运行的 dev server 才能起画布。

参与步骤

  1. 从 onlook.com 下载桌面应用（或从 github.com/onlook-dev/onlook 自行构建）
  2. 用 GitHub 或本地文件夹导入项目，让它建 worktree、起 dev server
  3. 在画布上点选元素下指令，agent 用你已有的 Claude Code / Codex 改代码
  4. 审 diff，满意就开 PR，不满意就丢弃

风险提示
