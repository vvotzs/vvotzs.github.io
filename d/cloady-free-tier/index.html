优惠内容

Cloady 是 NeptoLab 的 PaaS（类似 Railway / Render），按声明的 CPU、内存、SSD 计费，并提供免费层与部分区域的免费试用：整个工作区合计 0.5 vCPU、1GB 内存、5GB SSD 以内为 $0/月，超出才需绑卡付费。支持 GitHub 仓库推送自动部署、Docker 镜像、直接上传目录与模板市场（WordPress、Vaultwarden、Nginx Proxy Manager 等），每个 Web 应用自动分配 xxx.cloady.io 子域名与 TLS，另有 REST API、CLI、Terraform 与 MCP。新条款对新账号自 2026-11-02 生效。

参与条件

需用可正常收信的真实邮箱注册（禁止临时邮箱与批量注册）；免费额度是整个工作区共享，多开应用会超；超出免费额度且未绑卡会提示升级，不会自动扣费；禁止挖矿、Tor、IRC 等用途；免费层/试用区域官方可能随时调整。

参与步骤

  1. 打开 cloady.com，用常用邮箱注册并完成验证码登录
  2. 系统自动建好工作区，点 Deploy 选择 GitHub 仓库 / 镜像 / 上传目录 / 模板
  3. 地区选 EU1、USE1 或 USW1，资源控制在工作区免费额度内，确认页面显示 $0.00/mo
  4. 部署完成后访问分配的 cloady.io 域名（Docker 镜像部署若默认端口识别不到，改用带 EXPOSE 的 Dockerfile 或 API 指定端口）
