优惠内容

Sesame（Sesame AI, Inc.，Oculus 联合创始团队创办）做的是语音优先的个人 AI，官网现有四个角色 Maya、Miles、Simone、Charlie，在 iOS / Android app 里直接打电话或发文字，登录后会记住与每个角色的过往对话。免费档 $0：每天 30 分钟通话时长（每日重置）与每周有限的 credits（文字、任务与更高智能档都用它，每周重置），所有功能各档一致；额度用完仍可文字聊天，但模型智能降低、部分能力受限。Plus $20/月为每天 2 小时（4×）与 4× 周 credits，Pro $100/月为每天 10 小时（20×），另有 1 小时 $5 / 5 小时 $20 的加时包、1,000 credits $5 / 5,000 credits $20 的加购包（一次性购买不过期、排在套餐额度之后使用），Plus 可免费试 7 天，订阅通过 App Store / Google Play 管理。Sesame Link（link.sesame.com）把终端里的编码 agent 接到手机上：在跑 Claude Code、Codex、Pi、Cursor、Hermes、OpenCode 的电脑上装一个 CLI 并登录同一个 Sesame 账号，就能用浏览器 web client，或直接给 Sesame 角色打电话，问「What are my sessions doing?」逐个听 session 状态、说「Focus on …」聚焦某个 session 与 Claude/Codex 实时对话、口头批准或拒绝权限请求、让它开新 session 或结束 session；代码、工具与账号始终留在你自己的电脑上，Link 只做云端中转。

参与条件

免费档无需绑卡；通话时长每天重置、credits 每周重置，通话用 talk time、任何「替你去办」的任务用 credits，Max 智能档两者同时消耗；额度用尽后仍可文字但能力受限；Sesame Link 需要 Sesame 账号，并在电脑上装 CLI、已安装并登录对应编码 agent（Claude Code 还需 tmux 3.4+，桌面版不算），只支持 macOS 与 x86-64 Linux（preview）；Claude Code 完整支持，Codex / Pi / Cursor 为 preview，Hermes / OpenCode 为 experimental；未上架地区只能用网页 Research Preview，功能比 app 少；官方仅正式支持英语，中法德西意日韩为早期支持、可靠性较低。

参与步骤

  1. 在 App Store / Google Play 搜「Sesame: Personal Agents」安装（未上架地区用 app.sesame.com 网页版），注册并登录
  2. 挑一个角色（Maya / Miles / Simone / Charlie）直接打电话或发文字，免费档每天 30 分钟、每周限量 credits
  3. 想遥控编码 agent：在跑 Claude Code / Codex 的 Mac 或 Linux 上执行 curl 安装脚本，再运行 sesame-link auth login 并选好默认文件夹
  4. 在 Sesame app 里给角色添加 Sesame Link，之后打电话说「What are my sessions doing?」「Focus on …」即可；也可在 link.sesame.com 的 web client 操作
  5. 额度不够就在 app 的 Plan 页升级 Plus / Pro 或买加时包；不想付费就等每日 / 每周重置

风险提示

免费档「每周有限 credits」官方未公布具体数值，任务类使用消耗多快未知（标「待核实」）；value 里的 ≈$5/月是按 Plus $20 = 4× 免费通话时长折算的估算，不是官方标价；Sesame Link 没有单独价目页，官方未说明 Link 本身是否额外收费，语音操控会消耗 Sesame 的 talk time / credits（标「待核实」）；app 未在中国大陆、香港、印度等地上架，只能用功能较少的网页版；编码 agent 跑在你自己电脑上，过长的计划、文件内容与多数 MCP 参数无法在电话里完整读出，需回 web client 或终端确认；付费订阅在 App Store / Google Play 内购，取消要走商店，试用后别忘了取消。
